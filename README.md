One funny line: a single joke that lands on a cold read — the GPS took the scenic route past the ex's house, and now the GPS and its owner share a therapist.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only, no network, no randomness) writes the entry line to `/output/entry.txt` — 108 characters, inside the gate's 1–200 characters — so both grader runs write identical bytes.
